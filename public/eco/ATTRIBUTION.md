# Base de aberturas ECO

`openings.json` é gerado por `scripts/build-eco.mjs` a partir do dataset
[lichess-org/chess-openings](https://github.com/lichess-org/chess-openings),
distribuído sob **CC0-1.0** (domínio público).

Formato: chave = FEN sem os contadores de lance; valor = `[código ECO, nome, linhas catalogadas que passam pela posição]`.
